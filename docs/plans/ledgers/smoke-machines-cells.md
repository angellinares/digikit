# Ledger: the patch-time machine fixtures and their smoke cells are removed

Do not merge before the new tests pass on the device and an independent review. Status: the tests are written and have not run on a device (no emulator runs were allowed). The deletion commit merges only after the pin of `equiv-dt2-sine` is set (see the audible row).

Why: only three fixtures used patch-time `[[entry]]` rows of the `machines` registry: `test/machine-clone` (DT2), `test/dn2-clone` and `test/dn2-pages` (DN2). Since R12-6 the machine hooks are in `machines.dks`, and nothing loads that file for a patched-in row (the runtime finds a service file only for a hard NEED of a selected module, `loader/discover.rs`). Every real machine is a run-time `.dkm`. So the three smoke cells fail, and the fixtures tested a path nobody uses. Removed: the three fixtures, their cells in `tests/patchkit/smoke/matrix.toml`, 54 keys of `goldens.json`, the three `select.toml` files, `tools/patchkit/pk_proof_pages_dn2.py`, `tools/patchkit/pk_dn2_common.py` (its helpers, no other user), the clone configs of `pk_tiers.py`, the wasm and Python tests that used them (replaced by other fixtures where the test is generic), and the allocations in `types.toml` (now retired comments). patchkit refuses a patch-time entry of the `machines` registry (`refuse_entries` of `core/machines`; host test `a_registry_that_refuses_entries_names_the_module_and_the_reason`).

Open points for the review

1. The slot-to-Sound-word mapping (slot n is halfword n of the Sound array from +0x14 of the Sound object) is assumed from findings 02 and 119 (the mirror index of the parameter row is the word index). The DT2 test (`machine-rows-dt2`) asserts that `edit.index` equals the decoded Level mirror; this is also unproven on a device. `machine-rows-dn2` asserts the exact indices 26, 27, 29, 30 (the slots of `test/dyn-dn2`, `build/gen/gallery.json`) and that they equal the decoded mirror index; `machine-pages-dn2` asserts the word equals the decoded mirror index of the parameter and keeps the distance between pages (that fixture has no committed gallery).
2. The DN2 audio mirror address 0x8000487c is the one of the removed `select.toml` (DN2 1.12). The list position is 5 DOWN presses from FM TONE: FM TONE, FM DRUM, WAVETONE, SWARMER, MIDI, then the first run-time machine (the patch-time entry sat before MIDI at 4; the hint of the round trip test is 5).
3. The decoded row expectations (names, titles, ranges) come from `build/gen/gallery.json` of `test/dyn-dn2` and the fixture sources; not seen on a device yet.
4. A project with a run-time type loaded on the stock image (no runtime) is not tested; the round trip covers a runtime image without the module. Say if the uninstall path needs its own test.
5. (parked with `test/dyn-dn2-pages`.)
6. The empty knobs are those whose decoded code is 0 (knobs A, D, G, H of `test/dyn-dn2`). The old proof had A to D filled; whether a turn of knob A or D (slots 25 and 28) is really inert is first seen on a device. The knob is turned before TRIG 1 is held: with TRIG held the firmware may record a step p-lock instead of editing the Sound word, so the held-note step only polls the engine word of that voice until it equals the Sound word. It assumes the held note uses voice slot 1.
7. The DN2 TX frame (0x80005e60, type word +0x94, voice words +0xda + 0x92 v) and the audio mirror 0x8000487c are DN2 1.12 addresses without a port anchor; they are named constants in `machines-kit.ts` with the findings that give them (02, 06). The voice slot of the held note (1) assumes the round robin from 0 after the boot and one earlier TRIG; first seen on a device.
8. `trackType` reads the DT2 track object, so the DN2 tests read the audio mirror.
