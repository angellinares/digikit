## Working rules learned

- At most one heavy emulator job at a time; agents check `uptime` (load < 16) before device runs. Two overlapping gates reached load 50-75 and caused timeouts.
- build/*.dko.json drift: restore it only if `patchkit:objects-check` stays green without it; otherwise rebuild and commit.
- A coder's report of an edit is not proof: grep the file before a landing step depends on it.
- `mise run test:full` is blocked for sub-agents by a hook; the coordinator runs it with `DIGI_GUARD=off mise -C <lane> run test:full`.
- Rebuild a lane's daemons with `uv run python -m tools.devtools.verify_build daemons --env-out dist/daemons.json`.
